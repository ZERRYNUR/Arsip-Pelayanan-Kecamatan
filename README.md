# Website Pencatatan Pelayanan Kecamatan

Website ini dirancang untuk mencatat dan mempermudah pengelolaan layanan yang dilakukan oleh kecamatan, termasuk:
- Pembuatan KTP (Kartu Tanda Penduduk)
- Pembuatan KK (Kartu Keluarga)
- Pelayanan terkait Kependudukan
- Pengurusan Izin
- Surat Keterangan Tidak Mampu (SKTM)

## Fitur Utama
- **Manajemen Data**: Sistem pencatatan yang terstruktur untuk setiap jenis pelayanan.
- **Pelacakan Permohonan**: Melacak status pengajuan dokumen secara real-time.
- **Notifikasi**: Memberikan pemberitahuan terkait proses dan status layanan.
- **Antarmuka Pengguna Responsif**: Mendukung berbagai perangkat, termasuk desktop, tablet, dan ponsel.

## Teknologi yang Digunakan
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP (XAMPP)
- **Database**: MySQL
- **Framework** : Bootstrap
